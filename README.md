# 🍔 FreshBite — Online Food Ordering Platform

**FreshBite** is a modern, responsive frontend-only food ordering platform developed as part of the **Free Web Development Internship Online** task by **Data Alcott Systems**.

The application allows users to discover restaurants, explore food menus, view detailed food information, add items to a shopping cart, manage their wishlist, complete a simulated checkout process, and manage their account.

The project focuses on providing a realistic food-delivery experience with a clean UI, responsive design, reusable components, client-side state management, and interactive frontend functionality.

## 🎯 Project Objective

The objective of FreshBite is to develop a complete frontend food-ordering experience that simulates a real-world food delivery platform.

The project demonstrates practical knowledge of:

* Frontend development
* Responsive web design
* React component architecture
* Client-side routing
* State management
* Form handling and validation
* Shopping cart functionality
* E-commerce logic
* Local data management
* User interface and user experience design

## 🚀 Getting Started

Follow the steps below to run FreshBite locally.

### 1. Clone the repository

```bash
git clone https://github.com/surbhisingh1507/freshbite-food-ordering.git
```

### 2. Navigate to the project directory

```bash
cd freshbite-food-ordering
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Open the local URL displayed by Vite in your browser.
